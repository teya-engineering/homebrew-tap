# Teya-engineering Tap

## How do I install these formulae?

`brew install teya-engineering/tap/<formula>`

Or `brew tap teya-engineering/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "teya-engineering/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
